■ 这是什么

  一个在自己电脑上跑的 AlgoForge，面向零基础，
  按 6 周 42 天排好了课表。

  · 共 100 道题，其中 100 道能自动判题（写完点「运行」直接告诉你对不对）。
    也就是说全部都能判，没有例外。
  · Python 和 Java 都能写、都能判题。每道题都有中文题干、零基础讲解和参考代码。
  · 全程不需要联网，也不需要注册任何账号。你的代码不会被发到任何地方。
  · 不用装 Python，不用装 Java —— 需要的东西都在这个包里了。
  · 「八股文」板块：Java 面试题 392 道、AI 面试题 43 道，每题一句话回答 + 要点 + 常见追问，
    其中 18 道配了一步一步的动画。


■ 怎么开始（三步）

  第 1 步　解压
      把压缩包解压到一个固定的文件夹，比如  D:\Hot100
      ★ 不要在压缩软件里直接双击运行，一定要先【完整解压】出来。
      ★ 解压后不要再移动或改名这个文件夹（桌面快捷方式会指向它）。

  第 2 步　双击「开始使用.cmd」
      会弹出一个黑色小窗口，它会：检查文件是否齐全 → 解除网络锁定 →
      在桌面建快捷方式 → 启动程序。看完提示按任意键关掉即可。

  第 3 步　等界面自己打开
      十几秒后会弹出程序窗口。以后直接双击桌面的
      「AlgoForge」就行，不用再跑第 2 步。

  想结束时，直接关掉程序窗口 —— 后台服务会跟着自动停，不会有东西
  留在后台偷偷跑。

  （极少数情况下，程序没能用 Chrome/Edge 开出独立窗口、退回了你的默认
  浏览器。这时它分不清哪个标签页是它自己的，就不会自动停。程序会弹窗
  告诉你这一点，并给出停止用的文件路径：程序目录里的
  launch\stop-hidden.vbs，双击即可。）


■ 第一次打开要等一会儿，那是正常的

  界面右上角会先显示「正在加载 Python 环境」。这是在把 Python
  运行环境载入浏览器，大约 10~20 秒，变绿之后 Python 才能运行。
  之后每次打开也要几秒，属于正常现象，不是卡死了。

  这个灯只管 Python。**写 Java 不用等它** —— 切到 Java 就能直接点运行
  （第一次编译会多花一两秒，之后就快了）。


■ 杀毒软件 / Windows 拦住了怎么办  ← 最可能遇到的问题

  这个程序没有购买代码签名证书（那是一笔按年付的实名费用），
  所以 Windows 和国产杀毒软件很可能会拦一下。它拦的是
  「不认识的来源」，不是「检测到了病毒」。

  会遇到的几种拦截，以及怎么处理：

  ① 解压后双击 .cmd，弹出「Windows 已保护你的电脑」蓝色窗口
     → 点窗口里的【更多信息】，再点【仍要运行】。

  ② 弹出「打开文件 - 安全警告：无法验证发布者」
     → 点【运行】。
     （想一次性避免①②：解压【之前】先右键压缩包 →「属性」→
       勾选右下角的【解除锁定】→ 确定，再解压。）

  ③ 杀毒软件报「发现风险程序」并删除/隔离了文件
     → 到杀毒软件的「隔离区 / 信任区」把文件恢复出来，
       并把整个程序文件夹加入白名单，然后重新解压一次。
     → 如果不放心，可以先不要恢复，问问发给你这个包的人。

  为什么会被误报？因为这个程序恰好凑齐了误报的典型特征：
  没有签名、自带运行时、会在本机开一个只有自己能访问的小服务、
  还会调用编译器编译你写的代码。这几件事单看都很正常，
  凑在一起就容易被启发式引擎标记。

  一个可以自己核实的事实：包里两个可执行文件都是**官方原版、
  带有效数字签名**的，你可以右键 →「属性」→「数字签名」自己看：
      runtime\node\node.exe      签名者：OpenJS Foundation
      runtime\jdk\bin\java.exe   签名者：Eclipse Foundation
  它们没有被改动过。


■ 你写的东西存在哪里？会不会丢？

  代码、笔记、进度、笔记里贴的图，都存在浏览器的数据目录里：
      %LOCALAPPDATA%\Hot100Trainer
  （把这一串直接粘到文件资源管理器地址栏就能打开）

  注意：它们【不在】程序文件夹里。所以——

  · 覆盖更新程序文件夹，不会弄丢你写的任何东西。
  · 但是把浏览器数据清掉、或者删掉上面那个目录，就真的没了。

  ● 程序会自动帮你留快照（不用管，也不联网）

  每次打开程序、每次关窗口，它都会把你的数据存一份到程序文件夹里的

      backup\

  这个文件夹解压后就在，打开就看得见。里面有三种文件：
      hot100-snapshot-*.json   程序自动存的，保留最近 10 份
                               外加「内容最多的那一份」，其余自动清理
      hot100-backup-*.json     你自己点「导出」存的，程序**永远不会删**
      hot100-events.log        ★别删它★ 程序的运行记录，每次开/关记一行。
                               万一哪天进度莫名变成 0，这是唯一能查出原因的
                               东西。里面只有时间和「键的名字」，
                               没有你的任何代码和笔记，可以放心发给别人。

  （第一次打开时还没有 .json 快照 —— 那时文件夹里只有这个 .log 和一份说明，
    是正常的，不是出错。）

  为什么要有它：浏览器里的存储偶尔会自己出问题（清空、损坏、被清理软件
  扫掉）。真遇上了，程序**下次一打开就会在最上面弹一条黄色横幅**，写着
  「这次打开时一条数据都没有，但 backup 里存着一份 X 月 X 日的存档」，
  点横幅上的「去恢复」就行 —— 会先给你看内容摘要，确认无误再写入。

  ★ 看到那条黄横幅不用慌 ★ 它的意思是「东西还在，去拿回来」，
  不是「程序坏了」。
  （横幅只在一条数据都不剩时出现。要是只丢了一部分，自己打开
    「💾 备份 / 恢复」，第 ② 节最上面列着全部快照。）

  想换个位置存？在程序文件夹里建一个 backup-dir.txt，里面写上路径即可
  （相对路径按程序文件夹算，也可以写绝对路径如 D:\我的备份）。

  它有三条保命规则：
    · 快照里没有任何代码/笔记/进度时**不写入** —— 免得数据没了之后一开程序，
      反手把仅有的好快照挤掉（那比没备份还糟）
    · 内容和上一份完全一样时不重复写 —— 免得连开十次就把十份历史换成同一份
    · 轮换时永远不删「内容最多的那一份」

  ★ 但它替代不了你自己导出 ★
  快照和浏览器数据在同一台电脑上，重装系统、硬盘坏了就一起没了。
  界面右上角「💾 备份 / 恢复」→「导出」，存到网盘或 U 盘 ——
  这才是唯一能带走、换电脑时唯一能搬过去的存档。
  超过 7 天没导出，那个按钮会变成橙色提醒你。


■ 怎么更新　← 很简单，双击一次就行

  绝大多数更新是「界面更新包」，一个约 11 MB 的 zip，微信/QQ 直接就能发。

  你要做的只有两步：

    第 1 步　把对方发来的「Hot100 更新包 vX.Y.Z.zip」**另存**到程序文件夹里
            （就是有「开始使用.cmd」的那个文件夹；存到桌面或"下载"里也行）
            ★ 存 .zip 文件本身，不要先解压

    第 2 步　双击程序文件夹里的「更新.cmd」

  它会自己找到更新包、检查完整性、关掉程序、换上新版、再启动回来。
  也可以更省事：直接把那个 zip 拖到「更新.cmd」的图标上放开。

  更新过程中它会做几项检查，任何一项不过就**原样退回**、绝不半途而废：
    · 这个包是不是本程序的、内容完不完整（传输中断会被查出来）
    · 这个包配不配得上你这一版程序（配不上会让你找对方要整包，而不是硬装）
    · 换完之后界面文件是否完好（有问题会自动回滚到更新前那一版）

  **你写的代码、笔记、进度全程不会被碰到** —— 它们不在程序文件夹里（见上一节）。

  少数情况对方会发**整包**（一百多 MB、里面有 runtime 文件夹）。
  那种情况不用「更新.cmd」，按顺序做这三步：

    ① 先把旧文件夹里的整个 backup 文件夹，拷到新解压出来的文件夹里。
       ★ 你的全部存档都在里面。这一步别跳，也别只拷一部分。★
    ② 双击新文件夹里的「开始使用.cmd」，桌面快捷方式会自动指到新的那份。
    ③ 用几天确认没问题，再删掉旧文件夹。

  （走「更新.cmd」那条路不用管这些，backup 原样保留。）

  保险起见，更新前先用「💾 备份 / 恢复」导出一份。

  ⚠ 有一件事千万别改：程序固定用 5178 这个端口。
  浏览器是按「网址」来存数据的，端口一变就等于换了一个网址，
  你之前写的代码、笔记、进度会全部读不出来（数据还在，但程序
  找不到了）。所以配置里的端口不要动。


■ 出问题了，点哪里

  1. 界面能打开 → 点右上角「💾 备份 / 恢复」，里面第 ④ 节有
     【📋 复制诊断信息】。点一下，然后把复制到的那段文字发给
     给你这个工具的人。那段文字里有版本号、系统信息、最近的错误，
     但【不含】你的代码和笔记，可以放心发。

  2. 「我昨天写的东西，一打开就没了」→ 除了上面那段诊断信息，请把
     这个文件也一起发过去：
         <程序文件夹>\backup\hot100-events.log
     （右键「打开方式」→ 记事本就能看。里面只有时间和键的名字，
       没有你的代码和笔记，可以放心发。）
     这个文件就是专门用来查这类问题的 —— 它能分清「程序没打开过」
     和「打开了但数据没了」，光靠回忆是分不出来的。

  3. 界面根本打不开 → 启动日志在这里（同样可以粘到地址栏打开）：
         %LOCALAPPDATA%\Hot100Trainer\launcher.log
     把最后几十行发过去即可。

  4. 想彻底重来 → 关掉程序，双击 launch\stop-hidden.vbs 确保
     服务停了，再重新双击桌面快捷方式。


■ 常见问题

  Q：需要联网吗？
  A：不需要。程序本身、Python 环境、代码编辑器全都在包里，
     断网也能正常刷题。

  Q：会上传我的代码吗？
  A：不会。程序只在你自己电脑上开一个本地服务，没有任何联网上报。

  Q：为什么它是用浏览器打开的？
  A：界面本来就是网页，用系统自带的浏览器显示可以省掉一整套
     外壳程序（能省一百多 MB）。它开的是独立窗口，用的也是
     单独的浏览器数据目录，和你平时上网的浏览器互不干扰。

  Q：我电脑上已经装了 Java，会冲突吗？
  A：不会。程序优先用包里自带的那份，不去动你系统里的设置。

  Q：能不能用我自己装的 JDK？
  A：可以。把程序目录里的 runtime\jdk 文件夹改名或删掉，程序就会改用
     你系统里装的那个（需要 JDK 11 以上，推荐 17 以上）。
     前提是 javac 已经在系统 PATH 上 —— 在命令提示符里敲 javac -version
     能打出版本号就说明可以。打不出来的话，装 JDK 时要勾选「添加到 PATH」，
     或者把 runtime\jdk 改回原名继续用自带的那份。

  Q：写 Java 时提示「程序包 java.awt 不存在」？
  A：包里自带的是精简版 Java 运行时，只含算法题会用到的标准库
     （java.util、java.io、java.math 这些都有）。图形界面、数据库
     之类的包没有带。算法题基本用不到；确实要用就按上一条换成
     自己装的 JDK。

  Q：能删掉这个文件夹吗？
  A：能，直接删就行，没有写注册表、没有装系统服务。
     只是别忘了先把上面说的数据目录备份出来。

  Q：占多大地方？
  A：解压后约 228 MB。大头是自带的运行环境
     （Java 约 69 MB、Node 约 82 MB）—— 就是为了让你什么都不用装。
     用完想省空间的话，整个文件夹删掉即可。


■ 包里都有什么

  开始使用.cmd              第一次双击它
  更新.cmd                  收到更新包后双击它
  backup                   你的存档（自动快照 + 你自己导出的备份 + 运行记录）
  使用说明.txt              就是本文件
  THIRD-PARTY-NOTICES.txt   第三方组件的许可声明
  dist\                     网页界面本体
  server\                   本地判题接口
  launch\                   启动 / 停止脚本
  node_modules\             本地服务器
  runtime\node\             自带的 Node（官方原版，v22.21.1）
  runtime\jdk\              自带的 Java（Eclipse Temurin 21.0.12.1，jlink 裁剪）


■ 关于第三方组件

  本程序附带了 Pyodide、Monaco 编辑器、Node.js、Eclipse Temurin JDK
  等第三方组件，它们各自的版权与许可证原文都完整收录在同目录的
  THIRD-PARTY-NOTICES.txt 里。里面也写明了这些组件的源码从哪里获取。
