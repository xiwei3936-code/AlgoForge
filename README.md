# AlgoForge

**让算法，清晰可见。** 一个在自己电脑上跑的力扣 Hot 100 刷题工具，面向零基础、准备 Java / Python 面试的人。

不用联网，不用注册，不用装 Python 和 Java —— 下载、解压、双击就能用。

当前版本：**3.0.0**（免安装绿色版，仅支持 Windows 10 / 11 64 位）

---

## 怎么用

### 第 1 步：下载

点本页面右上方绿色的 **Code** 按钮 → **Download ZIP**。

> 也可以用 git：`git clone` 本仓库。

### 第 2 步：解压

把 ZIP **完整解压**到一个固定的文件夹，比如 `D:\AlgoForge`。

- 不要在压缩软件里直接双击运行，一定要先解压出来。
- 解压后不要再移动或改名这个文件夹（桌面快捷方式会指向它）。

### 第 3 步：双击「开始使用.cmd」

它会检查文件是否齐全、在桌面建好快捷方式，然后启动程序。十几秒后程序窗口会自己弹出来。

以后直接双击桌面上的 **AlgoForge** 就行。

> 第一次打开时，右上角会显示「正在加载 Python 环境」，大约要等 10～20 秒，变绿后才能运行 Python。写 Java 不用等。

## Windows 拦截了怎么办

这个程序没有购买代码签名证书，所以 Windows 和杀毒软件可能会拦一下。它拦的是「不认识的来源」，不是「检测到了病毒」。

- **蓝色窗口「Windows 已保护你的电脑」**：点「更多信息」→「仍要运行」。
- **「无法验证发布者」**：点「运行」。
- **想一次性避免上面两种**：解压之前，先右键下载的 ZIP →「属性」→ 勾选右下角的「解除锁定」→ 确定，再解压。
- **杀毒软件隔离了文件**：到隔离区恢复，并把整个程序文件夹加入信任，再重新解压一次。

包里的两个可执行文件都是官方原版，带有效的数字签名，可以右键 →「属性」→「数字签名」自己核实：

| 文件 | 签名者 |
|---|---|
| `runtime\node\node.exe` | OpenJS Foundation |
| `runtime\jdk\bin\java.exe` | Eclipse Foundation |

## 你写的东西存在哪

代码、笔记、进度都存在本机的这个目录里，**不在程序文件夹里**：

```
%LOCALAPPDATA%\Hot100Trainer
```

所以更新或替换程序文件夹不会弄丢任何东西。另外，程序会把自动快照存到程序文件夹里的 `backup\`。

快照和数据都在同一台电脑上，换电脑、重装系统前，记得在程序右上角点「💾 备份 / 恢复」→「导出」，存到网盘或 U 盘。

> ⚠ 程序固定使用 `5178` 端口。请不要改它 —— 端口一变，之前的代码、笔记、进度就读不出来了。

## 常见问题

**需要联网吗？**
不需要。程序、Python 环境、代码编辑器、Java 编译器都在包里，断网也能刷题。

**会上传我的代码吗？**
不会。程序只在你自己电脑上开一个本地服务，没有任何联网上报。

**为什么界面是在浏览器窗口里打开的？**
界面本身是网页，借用系统自带的 Edge / Chrome 来显示，能省掉一百多 MB 的外壳。它开的是独立窗口和单独的数据目录，和你平时上网用的浏览器互不干扰。

**我电脑上已经装了 Java，会冲突吗？**
不会。程序优先用包里自带的那份，不动你系统里的设置。

**占多大地方？**
解压后约 230 MB，大头是自带的运行环境（Java 约 69 MB、Node 约 82 MB）。

**怎么卸载？**
直接删掉程序文件夹即可，没有写注册表、没有装系统服务。删之前别忘了先导出备份。

**出问题了怎么办？**
程序右上角「💾 备份 / 恢复」→ 第 ④ 节「📋 复制诊断信息」，把复制到的文字发给作者。里面有版本号、系统信息和最近的错误，不含你的代码和笔记。

更详细的说明（更新方法、快照规则、排查步骤）见包里的 **[使用说明.txt](使用说明.txt)**。
